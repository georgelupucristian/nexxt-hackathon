## Fix first

1. **serious** `label-content-name-mismatch` (2 elements; Goals): The aria-label replaces the visible text, so voice-control users saying what they see miss it (WCAG 2.5.3). Start the aria-label with the visible text, or drop aria-label and let the visible text be the name.
2. **serious** `aria-prohibited-attr` (1 element; Home + first-run tour): aria-label is not allowed on this element without a role. Add a suitable role (e.g. role="img") or move the label to visible text.
3. **moderate** `region` (10 elements; Welcome (cold load), How it works, Sign in, New goal editor): Put this content inside a landmark (&lt;main>, &lt;nav>, &lt;header>, &lt;footer>), or mark it aria-hidden if purely decorative.
4. **moderate** `landmark-one-main` (1 element; Welcome (cold load), How it works, Sign in, Home): Wrap the screen content in &lt;main>.
5. **moderate** `page-has-heading-one` (1 element; How it works, Sign-up (Start), Sign in, Home): Add one &lt;h1> per screen (it can be visually hidden).
6. **moderate** `landmark-no-duplicate-banner` (1 element; Goals, Goal detail, Activity, Transaction detail, Profile, Profile: privacy, Profile: accessibility): A top-level &lt;header> is a banner landmark; panels add a second one. Use &lt;div> for panel headers (or nest them inside the panel's &lt;section>/&lt;dialog>, where &lt;header> loses the banner role).
7. **moderate** `landmark-unique` (1 element; Goals, Goal detail, Activity, Transaction detail, Profile, Profile: privacy, Profile: accessibility): Same cause as the duplicate banner: the panel &lt;header> is a second banner with no name. Changing it to &lt;div> fixes both rules.
8. **focus** no visible focus on `input[type=range]` ("Suma pe săptămână") on Home: A range input with `appearance: none` loses the browser focus ring. Add `input[type=range]:focus-visible { outline: 2px solid currentColor; outline-offset: 4px }` (or ring the thumb via `::-webkit-slider-thumb`).
9. **layout shift** CLS above 0.1 on Welcome (cold load) (0.15), Goals (0.17); sources under Performance. Reserve the space before content arrives: fixed `width`/`height` or `aspect-ratio` on images and the mascot, `min-height` on cards whose numbers fill in after load, and animate entrances with `transform`/`opacity` only.
10. **bundle** one 903 kB JavaScript chunk (262 kB gzip): split by route with `React.lazy`.

## Scope and limits

- Automated checks find roughly a third to a half of WCAG issues. Screen-reader passes (TalkBack, VoiceOver), zoom to 200% and real-device performance still need a person.
- Only the default demo state is audited; empty states, error states and the sheets opened from buttons are not.
- The report lists problems only. Fixes belong in `app/src` and are tracked separately.
